What is the Tenant Builder?
A queue-triggered provisioning system: a single message kicks off tenant setup, permissions, and deployment of ~8,000 SQL objects. Full tenant online in ~3 hours, across 5 environments and 3 Snowflake accounts.
What does the Patch Installer do?
Propagates a single schema or database change across every environment and tenant database at once, instead of applying it by hand 120 times — cutting manual-deployment error across the fleet.
How is schema drift caught across 120+ tenants?
A schema and tenant comparison utility diffs expected vs. actual structure across tenant databases, catching drift before it surfaces as a production data issue.
How is data validated at scale?
A Data Validator (Streamlit UI + CLI + CI/CD) runs large-scale reconciliation across 150+ of the 200 gold tables, each holding 1M+ rows — schema, row-count, row-hash, statistical, duplicate, and custom-SQL checks, with automated Excel reconciliation reporting.
